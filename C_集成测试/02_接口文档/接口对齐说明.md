# 接口对齐说明（C岗 9.29）
## 模块连接关系
dvp_capture（摄像头采集） → top顶层 → hdmi_tx（HDMI输出）

## 信号格式定义
1. cam_din：8bit，摄像头输入，两个字节拼成16bit RGB565
2. rgb565_out：16bit，R[15:11],G[10:5],B[4:0]
3. pixel_valid：高电平代表当前rgb565_out数据有效
4. hsync/vsync：行场同步信号，来自摄像头

## 接口检查
- 数据位宽：DVP输出16bit，HDMI输入16bit，位宽匹配 ✔
- 同步信号：行、场同步直接贯通
- 数据有效：pixel_valid控制输出数据，无有效数据输出0
